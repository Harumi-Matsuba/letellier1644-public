# 方法・数字・AI の使用・限界

## 画像
- BnF Baluze 103（Gallica ark:/12148/btv1b9001389d）。f. 50r＝111コマ、f. 50v＝112コマ。openapi.bnf.fr の IIIF から原寸（4864×6996）で取得した。画像はこのリポジトリに含めていない。
- 鍵の確かめに使った兄弟書簡：f. 230r（486コマ）と当時の解読文 f. 232r（490コマ）。語の符号の確かめに f. 171r（366）、f. 189r（402）、f. 200r（424）、f. 230v（487）を見た。

## 鍵（`data/key.tsv`）
1. 土台は友清理士氏の表（Cryptiana louisxiv0.htm「Le Tellier-Marca Cipher (1644)」の画像）を、記号名に置き換えたもの。表の各列の記号を記号名で書き写したものが `data/tomokiyo_table_signs.tsv`。
2. 兄弟書簡 f. 230r の1〜21行を記号名で書き起こし（`data/f230r_tx.txt`）、当時の解読文 f. 232r の該当部分（`data/f232r_ref_l1-21.txt`）と行ごとに動的計画法で対応させ、記号ごとに当たった字を数えた（`src/align_sister.py` → `data/f230r_sign_counts.tsv`、記号ごとの対応は `data/f230r_aligned.tsv`）。424記号のうち、鍵の値に当たったのは 406（直す前の鍵）、412（直した後の鍵）。表にない値・記号を足した：R＝c、ʒc・ʒx＝r、ꝺ＝r、ℒ＝M、Ꝺ＝h、k＝u、小さな o＝z、小さな ʒ（z3）＝s、ff＝d（a のほか）、6＝l（t のほか）。
3. 語の符号：=9 pour、=11 que、=12 qui、=26 vous、=32 Barcelone、81 faire、39 Catalogne、=y Monsieur le Mareschal、=3 de La Motte、=11 =o la Reyne、=l =m du Roi、=83 le Gouverneur（f. 230r 21行目）。=3 は f. 230r と f. 200r、=11 =o は f. 189r の3か所と当時の解読文の照合で確かめた。
4. source の列：T＝友清氏の表にある、S＝f. 230r／f. 232r の照合で確かめた、X＝別の AI との照合で分かれた記号、C＝f. 50 の文脈だけからの推定。
- **表との照合**：source に T を含む行の主な値は、すべて `data/tomokiyo_table_signs.tsv` の該当する列にある（突き合わせのコマンドは NUMBERS.md）。別の値（6＝l、u＝y など）の多くは表になく、f. 230r の照合（S）から来ている。
- 照合の途中で直したこと：
  - 6 と σ形、y と横線のある y は別の記号（別の AI との照合で分かった。表の列分けのとおり）。ただし f. 230r では 6 が l にも6回使われていた（la Vallee、lettre など）ので、6 の別の値 l は残した。
  - y の主な値を n としていたのは誤りで、表どおり g に直した。f. 50 の y の3か所は soing・garde の g と liberté の b、f. 230r の4か所は g 3・b 1 で、n はない。
  - 曲がった x には、横線のないもの（f の列）と横線の通ったもの（c の列）の2つの形がある。Codex はどちらも ae と呼んでいた。
  - mz には、尾に横線のある形（表の s の列の m7）と、横線のない巻いた尾の形（表の i の列）がある。f. 50 の17か所を画像で1つずつ見ると、横線のある6か所はすべて s、横線のない11か所はすべて i だった。後者を mi とした。
  - i の値の q は表の i の列の 9 形の記号、ℓ は表の x の列の記号とみなした。

## 書き起こし（`data/transcription_f50.txt`）
- Claude が原寸の行画像を見て、記号名で1回書き起こした（`data/transcription_f50_before_xcheck.txt`）。
- 2回目：別の AI（OpenAI Codex CLI、ChatGPT アプリ同梱 codex-cli 0.163.0-alpha.10.2、既定のモデル）に、画像と記号名の一覧（形の説明だけ。値・1回目の書き起こし・鍵・解読文は含めない）だけを渡し、5回独立に書き起こさせた。1〜3回目は1行1枚（`second/PROMPT.md`）、4〜5回目は1行を左右2枚に切った画像（`second/PROMPT_halves.md`）。5回とも、実行記録にコマンドの実行やファイルの読み込みはなかった。
- 1回目と Codex 1〜3回目の一致：633記号のうち 565・554・559、3回とも一致 546。食い違いを原寸で見直し、σ形10、横線のある y 9、24 の2か所などを直した（`second/RESULT.md`）。
- 5回の投票：最終の626記号のうち、5回とも同じ 580、多数が一致 612、多数が別の名前 12、多数なし 2。多数が違った15か所（再改訂前）を画像で見直し、4か所を直した（`second/VOTE.md`）。
- **AI どうしの比較は、人による確認の代わりにはならない。人による書き起こしの確認はしていない。**

## 対照（`src/control.py`、`controls/run.sh` → `controls/results.txt`）
鍵の値をかき混ぜた鍵 1000 通りと、文字3連のフランス語らしさ（wordfreq の仏語上位5万語から作る）で比べた。

| 最終（32行） | 全記号（73） | −3.286 | −5.073 | 0/1000 |
| 最終（32行） | 友清氏の表の記号だけ（61） | −3.185 | −4.741 | 0/1000 |

- 「推定した値を外した鍵」は `controls/key_without_target.tsv`（9f、l、24、23hat を外した）。f. 50 そのものから値を決めた記号を使わなくても読める、という確かめ。
- 書き起こしと鍵を直すたびに値は動いた（照合前 −3.421、照合後 −3.458、y の修正後 −3.446、mz と mi を分けた後 −3.286）。どの版でも 0/1000。Codex の書き起こしには mi がないので、Codex の行の本物の値は mi の分け方に左右されない。

## 較正（`calib/`）
答えのある f. 171r の12〜24行目を同じ鍵で読み、読みを固定してから（SHA-256 を `calib/hashes_before_answer.txt` に記録）、当時の解読文 f. 172r と比べた。

| 測ったもの | 結果 |
|---|---|
| 記号ごとの精度（主な値と別の値を許す、`src/score_signs.py`） | 0.913（253/277）。読みを固定した時点の鍵では 0.924（256/277） |
| 記号ごとの精度（主な値だけ） | 0.874（242/277） |
| 読みの文字の一致（`src/calib.py`） | 93.6%（337/360） |
| 鍵を機械的に当てただけの文字の一致 | 84.2%（303/360） |

誤りの例と限界は `calib/RESULT.md`。0.924 から 0.913 に下がったのは、較正用の書き起こし（固定済み）が mz と mi を分ける前のもので、i に当たる mz に今の鍵では値が合わないため。13行だけの較正で、盲検も完全ではない（同ページの冒頭に当たる f. 172r の7行を、先に NoAutopilot の書き起こしで読んでいたため、1〜11行目は使わなかった）。較正で分かった「横線のない 12 19＝qu'il」「9 の上に小さな g＝Sr」は、答えを見た後に分かったので鍵には入れていない。

## 再現できる範囲
- f. 189r・f. 200r・f. 230v での語の符号の確かめと、f. 50 の拡大画像による判断は、リポジトリに含めていない画像（SOURCES.md のコマ番号）に基づく。f. 190r・f. 205r の当時の解読文は NoAutopilot の書き起こしを使い、含めていない。
- Codex の実行記録（JSON）は手元のパスを含むので含めていない。「コマンドの実行やファイルの読み込みはなかった」は、その記録を私たちが見て確かめたことで、このリポジトリからは確かめられない。

## 先行研究との関係
- 友清理士氏：鍵の表と、この書簡が「undeciphered」であること。
- NoAutopilot/cipher-lab（`ciphers/baluze103-letellier-marca-1644/`、最後のコミット f3dcded、2026-10-13、Status: partial／Verdict: parked）：f. 50 を友清氏の表で部分的に読んだ下書き（630記号中451に値）がある。こちらで使ったのは、Gallica のコマ番号の対応、openapi.bnf.fr から画像が取れること、f. 200r で 6 が l にも当たるという記録、f. 190r と f. 205r の当時の解読文の書き起こし（f. 189r と f. 200r の照合に使った）。f. 50 の書き起こしと読み、f. 230 の照合、較正は、彼らのものを使わずに作った。

## AI の使用
書き起こし・鍵の補い・解読・スクリプト・文書は、Anthropic の Claude（Claude Code、Claude Opus 5.5）が行った。書き起こしの照合に OpenAI の Codex を使った。対象の選定、作業の指示、公開の判断は人が行った。
